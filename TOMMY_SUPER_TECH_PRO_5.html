Networking Fundamentals

Network ndi kulumikizana kwa zipangizo kuti zitumizane data.

IP AddressAdiresi yozindikiritsa chipangizo pa network.
DNSImathandiza kupeza webusaiti pogwiritsa ntchito dzina lake.
DHCPImapereka ma IP address kwa zipangizo pa network zambiri.
RouterImalumikiza ndi kutsogolera traffic pakati pa ma network.
LAN / WANNetwork ya malo ochepa / yolumikiza madera akutali.
FirewallImasefa traffic potsatira malamulo a chitetezo.
📡

Wi-Fi Security Checklist

Malangizo otetezera router ndi Wi-Fi yanu.

  • Gwiritsani ntchito password yolimba komanso yapadera.
  • Sankhani WPA2 kapena WPA3 ngati ilipo.
  • Sinthani firmware kudzera pa malangizo a wopanga router.
  • Yang'anani zipangizo zolumikizidwa pa router yanu.
  • Musagawane password ndi anthu osadalirika.
Note: Dashboard iyi si scan router kapena network. Ndi malo ophunzirira okha.
